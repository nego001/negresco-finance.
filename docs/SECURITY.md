# Segurança

A criptografia real ainda não foi implementada. Requisitos planejados: Android Keystore, AES-256-GCM para dados sensíveis, TLS, KMS/HSM para chaves de servidor, Argon2id para verificadores de senha, auditoria e rotação de segredos.

Nenhuma aprovação textual de IA equivale a consentimento do usuário. Pix e investimentos reais exigem autorização explícita e parceiros regulados.

Não adicionar credenciais, chaves, tokens, arquivos .env ou dados financeiros reais ao Git.
